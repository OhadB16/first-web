SKY
Project for people who like to buy airplain someday

Overview

SKY Jet Store is a full-stack app (React + Node/Express) for browsing luxury jets, adding to cart, purchasing, and managing content like reviews and contact requests. An admin role unlocks moderation and product management.

Store nameSKY
StackReact, CSS, Node.js/Express, JSON persistence
Admin loginadmin / admin

How to Use the App

As a User UI

  • Register or login (☰ Menu → shown on top right).
  • Browse jets, search, and Add to Cart.
  • Proceed to Cart → Pay → see My Items.
  • Open Reviews to read/post a review.
  • Use Contact to send a message (persisted to the server).

As Admin role

  • Login with admin / admin.
  • Access Admin panel from the menu (add/remove products).
  • Moderate: delete Reviews and Contact messages.
  • View activity summaries via admin endpoints.

Tip: “Remember me” keeps you logged in (cookie-based). It does not autofill your browser password fields.

Pages

  • Store – product grid with search, add to cart.
  • Cart / Pay / Thank You – simple checkout flow (mock payment).
  • My Items – shows purchased jets.
  • Reviews – users can post; admin can delete.
  • Contact – submit a request; admin inbox for moderation.
  • FAQ & About – supporting content.
  • Theme toggle – light/dark across the app.

Roles & Permissions

User allowed

  • Register/login, add to cart, purchase, view My Items
  • Submit contact messages
  • Post reviews

Admin extra

  • Add/remove products (admin page)
  • Delete reviews and contact messages
  • Query activity endpoints

UI gating: admin-only controls are hidden for non-admins. Server enforcement: admin endpoints require header X-Username: admin (cookies are also used).

Server API (selected)

Base URL: http://localhost:3001. Static docs: /readme.html, /llm.html.

Auth & Me

  • POST /api/register – create user
  • POST /api/login – login (rememberMe supported)
  • POST /api/logout – logout
  • GET /api/me – current user (from cookies/header)

Products

  • GET /api/products – list all
  • POST /api/products admin
  • DELETE /api/products/:id admin

Cart & Purchases

  • POST /api/purchase/:username – record purchase
  • GET /api/purchase/:username – list purchases for user
  • POST /api/cart/:username – save entire cart
  • GET /api/cart/:username – get cart
  • DELETE /api/cart/:username/:jetId – remove one item

Reviews

  • GET /api/reviews?source=ask-the-aspects
  • POST /api/reviews – create review
  • DELETE /api/reviews/:id admin

Contact

  • POST /api/contact – submit message
  • GET /api/contact admin – list messages
  • DELETE /api/contact/:id admin

Admin Activity

  • GET /api/admin/activity admin
  • GET /api/admin/activity/sales?bucket=day|week|month|year admin

Run Locally

Server

cd server
npm install
npm run server     # starts on http://localhost:3001

Client

cd client
npm install
npm start          # opens http://localhost:3000

Optional packages (already referenced in project)

  • recharts (admin charts): cd client && npm i recharts
  • Stripe (future): @stripe/react-stripe-js @stripe/stripe-js

API Tests

# simple API script
npm run test:api     # runs server/tests/test.js

# e2e via node:test
npm run test:e2e     # runs server/tests/e2e.test.js
