Additional pages and how to use them

  • Contact page – submit requests to the company.
    • Admin view: browse all submitted requests and mark/handle/delete them. Data persists in server/data/messages.json.
    • Customer view: submit a new request through the form.
  • FAQ page – previously asked questions to save time before contacting support.
  • Reviews page – customers can post a review (appears instantly). Admin can delete reviews that are not appropriate (removes them from the JSON as well).
  • About page – background about the people and how the company operates.

How to operate: open the top menu (☰ Menu) and select Contact / FAQ / Reviews / About. Use admin / admin to see admin capabilities.

Role-based access & permissions

The app enforces a clear separation between a regular User and the Admin. UI and API are aligned so admin-only controls are visible only to admin, and the server re-validates every sensitive action.

  • Admin capabilities:
    • Contact desk: view all submitted messages, mark/handle, and delete messages.
    • Reviews: remove any review that violates policy.
    • Admin page access (back-office tools).
  • User capabilities:
    • Browse and purchase items, view “My Items”.
    • Submit contact messages.
    • Post reviews (which appear instantly).
    • No access to admin-only controls (no message inbox, no delete buttons, no admin page).
  • UI gating: Admin-only buttons/links are conditionally rendered in the client (e.g., the delete icon in Reviews, the Messages admin view). Regular users never see these controls.
  • Server enforcement: Admin actions require the header X-Username: admin (and CORS allows this header). Admin-only endpoints (GET/DELETE /api/messages, DELETE /api/reviews/:id) refuse non-admin requests. This guarantees permissions even if someone tries to call the API directly.

In short: there is a precise alignment between the user and admin flows, and the admin has specific capabilities that regular users do not.

All routes supported by the app (server)

Base URL: http://localhost:3001

  • GET /readme.html, GET /llm.html – static documentation pages.
  • POST /api/register – register a new user.
  • POST /api/login – login (supports “Remember me”).
  • POST /api/logout – logout.
  • GET /api/me – current user info.
  • GET /api/products – list of jets.
  • GET /api/purchase/:username – purchases per user.
  • GET /api/reviews?source=ask-the-aspects – load reviews.
  • POST /api/reviews – create a new review.
  • DELETE /api/reviews/:id – delete a review (Admin only, via X-Username: admin header).
  • GET /api/messages – read contact messages (Admin).
  • POST /api/messages – submit a contact message.
  • DELETE /api/messages/:id – delete a message (Admin).
